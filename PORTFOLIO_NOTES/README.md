# Portfolio Notes — LM Evaluation Harness Fork

## In plain language

The LM Evaluation Harness is a framework for running language-model benchmarks in a consistent way and comparing model outputs against defined tasks and metrics.

## Technical context

This repository is a fork of EleutherAI's upstream evaluation harness. The upstream framework provides task/configuration and model-backend infrastructure. Portfolio work should focus on pinned benchmark runs, dataset/licence provenance, evaluation configuration and reproducibility; do not claim benchmark results without recording exact model revisions, prompts, seeds, backend versions and scoring configuration.

## Provenance

This repository is a fork of [EleutherAI/lm-evaluation-harness](https://github.com/EleutherAI/lm-evaluation-harness). Upstream owns the evaluation framework, task catalogue, documentation, licences and release process. This folder holds portfolio-specific experiment and contribution notes only.
