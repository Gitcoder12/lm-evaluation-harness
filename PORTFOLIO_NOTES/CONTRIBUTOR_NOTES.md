# Contributor Notes — LM Evaluation Harness Fork

This repository is a fork of EleutherAI/lm-evaluation-harness. Follow upstream contributing guidance and licence terms.

1. Read upstream README, CONTRIBUTING.md, licence and task/plugin documentation.
2. Pin task, dataset, model and harness revisions for reproducible results.
3. Keep local configs, reports and custom examples separate from upstream task definitions.
4. For task/backend changes, include tests, expected metric and data provenance.
5. Do not publish custom datasets without licensing and privacy review.
6. Submit upstream fixes or tasks through upstream review; do not imply local fork changes are accepted upstream.
